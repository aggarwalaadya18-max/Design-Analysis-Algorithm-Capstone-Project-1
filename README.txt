MINI-COURIER PLANNER

1. Extract this ZIP file.
2. Open the extracted Mini_Courier_Planner_Ready folder in VS Code.
3. Open main.py.
4. Open Terminal > New Terminal.
5. Run: py main.py

If the terminal is not already in this folder, use VS Code File > Open Folder to open this extracted folder first.

The program uses only Python standard-library modules. No pip installation is needed.
It creates performance_results.csv after execution.
